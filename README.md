# React Router Client Demo

A small React app showing client-side routing with `react-router-dom`.

## Routes

- `/` redirects to `/dashboard`
- `/dashboard` shows the main workspace overview
- `/projects` lists project links
- `/projects/:projectId` shows a dynamic project detail route
- `/calendar`, `/reports`, and `/settings` show additional routed pages
- `*` renders a not-found page

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
